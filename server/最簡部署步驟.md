# 最簡部署步驟（全程網頁點擊，不用終端機）

只要照著點，大約 10 分鐘。全部在 https://dash.cloudflare.com 裡面完成。

> **先講清楚：這一步是選做的。**
> 不部署伺服器，App 一樣 100% 正常運作，所有運動紀錄、圖表、健康匯入全部照常。
> 伺服器只是讓統計數字能加密備份到雲端而已。不想弄就跳過，App 裡那個同步開關維持關閉即可。

---

## 第 1 步：建立資料庫

1. 打開 https://dash.cloudflare.com 並登入
2. 左邊選單找到 **儲存與資料庫 → D1 SQL 資料庫**（英文是 Storage & Databases → D1 SQL Database）
3. 按 **建立**（Create）
4. 資料庫名稱填：`chaihome-stats`
5. 按 **建立**

---

## 第 2 步：把表格建起來

1. 點進剛剛建好的 `chaihome-stats`
2. 上方分頁選 **主控台**（Console）
3. 把下面整段貼進去，按 **執行**（Execute）

```sql
CREATE TABLE IF NOT EXISTS stats_blobs (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  device_id    TEXT    NOT NULL,
  client_ts    TEXT    NOT NULL,
  received_at  INTEGER NOT NULL,
  version      INTEGER NOT NULL DEFAULT 1,
  iv           TEXT    NOT NULL,
  ciphertext   TEXT    NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_stats_device_time
  ON stats_blobs (device_id, received_at DESC);
```

看到成功訊息就可以了。

---

## 第 3 步：建立 Worker

1. 左邊選單選 **運算 Workers → Workers 和 Pages**（Compute → Workers & Pages）
2. 按 **建立**（Create）→ 選 **從 Hello World 開始**（Start with Hello World）
3. 名稱填：`chaihome-stats`
4. 按 **部署**（Deploy）

---

## 第 4 步：貼上程式碼

1. 部署完之後，按 **編輯程式碼**（Edit code）
2. 編輯器裡原本的內容 **全選刪掉**
3. 把 `server/src/index.js` 這個檔案的內容 **整份貼上**
   （在 GitHub 上打開這個檔案，右上角有複製按鈕）
4. 按右上角 **部署**（Deploy）

---

## 第 5 步：把資料庫接上 Worker

1. 回到這個 Worker 的頁面，上方分頁選 **設定**（Settings）
2. 找到 **繫結**（Bindings）→ 按 **新增**（Add）
3. 類型選 **D1 資料庫**（D1 database）
4. **變數名稱** 填：`DB`  ← 這三個字母一定要一模一樣
5. **D1 資料庫** 選：`chaihome-stats`
6. 按 **部署 / 儲存**

---

## 第 6 步：綁上你的網址

1. 還在 **設定**（Settings）頁
2. 找到 **網域與路由**（Domains & Routes）→ 按 **新增**（Add）
3. 選 **自訂網域**（Custom domain）
4. 填：`api.chaihome.cc`
5. 按 **新增網域**

Cloudflare 會自動處理 DNS 跟 SSL 憑證，通常 1 分鐘內就好。

---

## 第 7 步：設一組存取密鑰（建議做）

1. 還在 **設定**（Settings）頁
2. 找到 **變數和密鑰**（Variables and Secrets）→ 按 **新增**（Add）
3. 類型選 **密鑰**（Secret）
4. 名稱填：`SYNC_TOKEN`
5. 值：自己想一組長一點的亂碼，例如 `k7Qz2mXp9TvR4wLb8NcJ6hFsD3yGaE5u`
   **這組字串等一下要填進 App，先記下來**
6. 按 **部署 / 儲存**

> 這不是加密金鑰，只是用來擋掉不認識的請求。就算外流，對方拿到的還是解不開的密文。
> 不想設也可以，直接跳過第 7 步即可。

---

## 第 8 步：確認有沒有成功

用手機或電腦的瀏覽器直接打開這個網址：

**https://api.chaihome.cc/v1/health**

畫面上出現這行就是成功了：

```
{"ok":true,"service":"chaihome-stats"}
```

---

## 第 9 步：在 App 裡設定

打開 App →「設定」→「端對端加密」：

1. **伺服器位址**：按「填入 https://api.chaihome.cc/v1」那顆按鈕，或自己打
2. **存取密鑰**：填第 7 步那組亂碼（第 7 步跳過的話這格留空）
3. 按 **測試伺服器連線** → 看到「連線正常」
4. 打開 **啟用同步**
5. 按 **上傳**，再按 **下載**

看到「已解密：XX 筆訓練、XX 公里」就代表整條路都通了。

---

## 遇到問題

| 狀況 | 原因 | 怎麼辦 |
|---|---|---|
| 打開網址顯示「找不到這個端點」 | 網址打錯 | 確認結尾是 `/v1/health` |
| App 顯示「伺服器回應 401」 | 密鑰對不上 | 檢查第 7 步的字串跟 App 裡填的是否完全一樣（含大小寫） |
| App 顯示「伺服器回應 500」 | 資料庫沒接上 | 回第 5 步，確認變數名稱是大寫的 `DB` |
| 打開網址顯示 Cloudflare 錯誤頁 | 網域還在生效中 | 等 1～2 分鐘再試 |

任何錯誤訊息，直接截圖或複製給我，我幫你看。
